# Young-learner illustration bundle — credits

## Current state

This directory ships **placeholder SVGs** generated by
`scripts/gen-young-learner-bundle.js`. Each SVG is a simple labelled circle
matching the keyword in the corresponding `manifest.json` entry. They render
in the in-browser slideshow preview and the exported `.pptx` file as
recognisable visual anchors, but they are deliberately minimal.

The keyword mapping in `manifest.json` is stable: dropping real artwork
into this directory under the same filenames swaps the visual without
touching any code.

## Replacement plan (post-deploy)

To replace with proper artwork, pick **one** source pack to keep style
coherent:

1. **Storyset** — https://storyset.com/ (free, requires attribution).
   Pick a single People or Education pack so the visual style is
   uniform. Per Storyset's terms (https://storyset.com/terms),
   Slatework displays the attribution string
   `Illustrations by Storyset` in:
     a. The visible footer of the in-browser slideshow preview.
     b. The notes section of every exported `.pptx` file.
2. **Open Doodles** — https://www.opendoodles.com/ (CC0, no attribution
   required). Keeping a credit line for documentation is still good
   practice.

For each kebab-case stem in `manifest.json` (e.g. `farm-cow`,
`food-apple`, `school-pencil`), drop a corresponding SVG at
`<stem>.svg`. Strip embedded `<script>` tags from any imported SVG
before committing — the strict CSP will reject them anyway, but
removing them keeps the on-disk file matching what loads in production.

## Categories shipped (placeholders)

The placeholder bundle includes 107 entries across:

- Animals (~20): cat, dog, cow, pig, sheep, chicken, duck, horse,
  rabbit, mouse, bird, fish, bear, lion, tiger, elephant, monkey,
  frog, bee, butterfly.
- Food (~15): apple, banana, orange, bread, milk, water, rice,
  noodle, soup, cake, egg, cheese, chocolate, ice cream, pizza.
- Family (~10): mother, father, sister, brother, baby, grandmother,
  grandfather, family, friend, teacher.
- Body parts (~12): head, hair, eye, nose, mouth, ear, hand, foot,
  arm, leg, finger, tooth.
- Action verbs (~15): run, jump, walk, sit, stand, sleep, eat, drink,
  read, write, sing, dance, play, smile, listen.
- School objects (~12): pencil, pen, paper, book, notebook, ruler,
  eraser, scissors, glue, bag, desk, chair.
- Weather (~6): sun, cloud, rain, snow, wind, rainbow.
- Numbers (~5) + colors (~5): one through five; red, blue, yellow,
  green, black.
- Miscellaneous greeting tokens used by the fallback deck warmup
  keywords (hello, smile, discussion, pair work, friends, classroom,
  student).
