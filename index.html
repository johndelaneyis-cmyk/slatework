// FAQ

Honest answers.

Why use this instead of ChatGPT?

Three reasons.

  1. Pre-contextualized. Every tool already knows the country, language pair, CEFR level, format, audience. You don't write the prompt.
  2. Tutor-specific structure. Lesson plans come back with timed blocks, exit tickets, and differentiation notes. Worksheets ship with a separate answer key. Marking returns categorised errors and three feedback variants. ChatGPT can do these — but you'd type the same 200-word system prompt every time.
  3. Free, no signup, no quota panic. Slatework has its own daily rate limit that's plenty for an active tutor.

Use ChatGPT for open-ended thinking. Use Slatework when you need the same shape of output repeatedly.

Is this legal or tax advice?

No. The tax, insurance, and rate tools surface country-specific information — accurate to the date stamped at the bottom of each country's data file — but they're estimates and starting points, not professional guidance. Confirm with a local accountant, lawyer, or insurance broker before any decision that depends on the output.

How does it stay free?

Two paths.

  1. Affiliate links to tools you'd already pick — Wise, Stripe Link, the platforms themselves. We never recommend something we wouldn't use.
  2. An optional Pro tier later, for power users — saved drafts and bigger AI quotas. The 10 free tools stay free.
Is my student's writing private?

Yes. The marking accelerator and CEFR AI assessor send what you submit — pasted text, a Word doc, a PDF, or a photo of handwritten work — to Anthropic's API for processing. We never store it. We never log it. We never share or sell it.

That includes student names visible in the writing. If a paper has "Maria Hernandez" at the top, that string passes through Anthropic's API and disappears — it never lives on our servers.

The contract builder is fully client-side: your name, rate, and details never leave your browser. See the privacy page for the full posture, including what to do if you'd rather redact names before uploading.

My country isn't in the list — when?

The 7 launch countries (US, UK, CA, AU, NZ, IE, HK) ship first because their tax forms, rate ranges, and platform availability are confirmed-correct. India, Singapore, Philippines, and the EU are the next batch. The architecture is JSON country packs, so adding a new country is a pull request, not a rebuild. If you want yours sooner, email hello@slatework.tools — real demand jumps the queue.
